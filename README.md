# 🎓 Student Grade Manager

A simple Student Grade Management System built using Python.

## Features
- Add new students
- Enter marks for five subjects
- Calculate total marks
- Calculate percentage
- Automatically assign grades
- View all students
- Search students by roll number
- Store student records using JSON

## Technologies Used
- Python 3
- JSON
- Visual Studio Code

## How to Run

Open the terminal in VS Code and execute:

```bash
python3 student_grade_manager.py
```

## Project Purpose

This project was created to practise Python programming, functions, file handling, JSON, and conditional statements.
